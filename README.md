# Presupuestando

Aplicación web *mobile-first* para que profesionales autónomos de oficios preparen presupuestos y archiven tickets de gastos desde el lugar de trabajo.

## El problema

El equipo quiere comprobar si los profesionales de oficios necesitan una forma más directa de crear y compartir presupuestos y guardar justificantes desde el móvil. La necesidad aún está pendiente de validación con entrevistas y datos de usuarios; no se presenta como un resultado de investigación ya demostrado.

## Stack

- **Frontend:** React, Vite, React Router, Zustand, Axios, React Hook Form y CSS nativo.
- **Backend:** Node.js, Express, JWT y bcrypt.
- **Datos y archivos:** MongoDB Atlas y Cloudinary.
- **Despliegue previsto:** Vercel (frontend) y Render (API), sujeto a los límites y condiciones de sus planes.
